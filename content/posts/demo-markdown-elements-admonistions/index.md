## 什么是提示框

提示框（也称为“侧边栏”）用于提供与内容相关的支持性和/或补充性信息。

## 如何使用

在 Astro Cactus 中使用提示框，将你的 Markdown 内容包裹在一对三冒号 `:::` 中。第一对冒号还应包含你想要使用的提示框类型。

例如，使用以下 Markdown：

```md
:::note
突出显示用户应注意的信息，即使在快速浏览时也应留意。
:::
```

输出：

> **注意**
>
> 突出显示用户应注意的信息，即使在快速浏览时也应留意。

## 提示框类型

目前支持以下提示框类型：

- `note`
- `tip`
- `important`
- `warning`
- `caution`

### 注意

```md
:::note
突出显示用户应注意的信息，即使在快速浏览时也应留意。
:::
```

> **注意**
>
> 突出显示用户应注意的信息，即使在快速浏览时也应留意。

### 提示

```md
:::tip
可选信息，帮助用户更成功。
:::
```

> **提示**
>
> 可选信息，帮助用户更成功。

### 重要

```md
:::important
用户成功所必需的关键信息。
:::
```

> **重要**
>
> 用户成功所必需的关键信息。

### 警告

```md
:::warning
由于潜在风险，需要用户立即关注的关键内容。
:::
```

> **警告**
>
> 由于潜在风险，需要用户立即关注的关键内容。

### 小心

```md
:::caution
行动的负面潜在后果。
:::
```

> **小心**
>
> 行动的负面潜在后果。

## 自定义提示框标题

你可以使用以下标记自定义提示框标题：

```md
:::note[我的自定义标题]
这是一个带有自定义标题的提示框。
:::
```

输出：

> **我的自定义标题**
>
> 这是一个带有自定义标题的提示框。
